# RCB IPL Performance Dashboard

## Overview
This Power BI dashboard analyzes Royal Challengers Bengaluru (RCB) performance in the IPL.

## Tools Used
- Power BI
- Excel
- DAX

- Season-wise Analysis
- Boundary Analysis
